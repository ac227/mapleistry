## 2. Tabs

=== "方法一：SN1 机理"

    1. 离去基团离开，形成碳正离子  
    2. 亲核试剂进攻（从两面均可）  
    → 外消旋化

=== "方法二：SN2 机理"

    1. 亲核试剂背面进攻  
    2. 同时离去基团离开  
    → 构型翻转（100% 反转）

    | 特征       | SN1          | SN2          |

    | 溶剂影响   | 极性质子溶剂 | 极性非质子溶剂 |
